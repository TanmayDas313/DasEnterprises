System Requirements for TallyPrime

Official hardware and software specifications for optimal performance.

Operating System

Windows 10 (64-bit) or Windows 11 (64-bit). For server installations: Windows Server 2016 / 2019 / 2022.

Processor (CPU)

Intel Core i3 / i5 / i7 or equivalent AMD processor (2.0 GHz or higher speed recommended).

System Memory (RAM)

4 GB minimum. 8 GB or higher recommended for high-volume transactions and multi-user environments.

Storage Space

500 MB for application files. High-speed Solid State Drive (SSD) recommended for company data storage.

Network & Internet

High-speed broadband for e-Way bills, e-Invoicing, GST portal connectivity, and remote cloud access.

Display & Peripherals

1366 x 768 display resolution or higher. Standard thermal / laser printers for invoice printing.
